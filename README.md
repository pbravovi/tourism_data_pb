# tourism_data_pb
Overview of the International Data in Tourism using UN Tourism Data
Based on UN Tourism data our aim is to analyze international data in Tourism
This data is categorized in 7 groups
domestic, inbound, accommodation, macroeconomic, employment and SDGs
Here is a definition of each group:
domestic
inbound
outbound
accomodation
macroeconomic
employment
sdgs
if you need more information please to check some definitions please visit https://www.untourism.int/glossary-tourism-terms or https://unstats.un.org/unsd/publication/Seriesm/SeriesM_83rev1e.pdf#page=1
